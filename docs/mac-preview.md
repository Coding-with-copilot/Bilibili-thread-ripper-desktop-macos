# Mac 预览版：安装、验证与反馈

BTR Mac 预览版把已有的多连接下载器接入哔哩哔哩官方 Mac 客户端的播放窗口。它保留原播放器，只尝试接管符合条件的点播媒体请求。当前目标客户端为 **1.19.0**；其他版本的页面结构和请求方式尚未验证。

## 已验证到哪一步

- 测试副本能够启动、正常播放，客户端设置与播放器齿轮中出现 BTR 选项。
- 登录尚未测试。实际媒体下载是否经过 BTR，仍需读取下面的“诊断”计数；目前不能把“能够播放”当成“已加速”的证据。
- Mac 预览版不提供 BTR 自动更新、手动更新检查或客户端内卸载按钮。
- 封装后的 ASAR 完整性、本地签名，以及相关自动化测试已通过；这些检查不代替真实播放验证。

## 方法一：使用预览版压缩包

1. 下载 [Mac 预览版应用 ZIP](https://github.com/Coding-with-copilot/Bilibili-thread-ripper-desktop-macos/releases/download/preview/BTR-Mac-Preview-2026.9.29.1-d1-mac-preview.2-App.zip) 并解压。压缩包内的应用名为 `哔哩哔哩-BTR-diagnostic.app`。
2. 将应用放在本机非云同步目录，例如 `~/Applications`。完全退出官方客户端及先前的测试副本，再启动新副本。也可以在终端运行：

   ```sh
   open -n "$HOME/Applications/哔哩哔哩-BTR-diagnostic.app"
   ```

3. 如果 macOS 阻止打开下载的预览包，可改用下面的源码方法，从自己安装的官方客户端生成本地副本。预览包没有 Apple 开发者签名或公证。

副本与官方客户端使用同一份用户数据。不要同时运行两个实例；删除测试副本不会删除官方客户端应用。

## 方法二：从源码生成

需要 macOS、Node.js、未接入 BTR 的官方 `哔哩哔哩.app`。在本仓库根目录执行：

```sh
node tools/mac-port.cjs install '/Applications/哔哩哔哩.app' "$HOME/Applications/哔哩哔哩-BTR.app"
```

将第一个路径换成原版客户端的实际位置；第二个路径是**尚不存在**的输出应用。脚本会复制原版，向副本加入 Electron preload 和页面脚本，更新 ASAR 完整性哈希，再做无需开发者证书的本地签名。原版应用不会被修改。若输出已存在，脚本会停止，不会覆盖它。

生成后，先退出官方客户端，再运行：

```sh
open -n "$HOME/Applications/哔哩哔哩-BTR.app"
```

不要把输出放在 iCloud 等云同步目录：这类目录可能给 `.app` 附加 Finder 属性，影响本地签名校验。官方客户端升级后，请从升级后的原版重新生成副本，并重新验证播放兼容性。

## 如何判断是否真正加速

1. 打开一个普通点播视频，播放一段并拖到未缓存的位置。
2. 打开播放器齿轮菜单，找到 BTR 设置下面的“诊断”一行。
3. 查看这些字段：

   | 字段 | 含义 |
   | --- | --- |
   | `接管` | 当前视频已由 BTR 下载并交回播放器的媒体请求数；**大于 0 才能确认发生过接管**。换视频后重新计数。 |
   | `媒体 fetch/XHR` | 播放页发出的、文件名像媒体分段的请求数。大于 0 但 `接管` 为 0 时，结合“最近跳过”判断是哪条筛选条件没有通过。 |
   | `页面资源` | 页面观察到的媒体资源数，用于辅助判断请求是否可能绕过页面的 `fetch`／XHR。它本身不代表加速成功。 |
   | `最近跳过` | 最近一次媒体请求未被 BTR 接管的原因。 |

“已收到客户端播放地址”“视频数据已交给客户端”是 **Debug 模式**下的成功提示，默认不显示。要看这些提示，在客户端 BTR 设置中开启 Debug 模式；“显示错误”是另一个独立开关。没有提示，不等于下载未接管。

## 反馈问题时请附上

- macOS 和官方客户端版本，以及应用能否启动、登录和播放；
- 播放器齿轮与客户端设置中是否出现 BTR；
- 播放并拖动后，“诊断”一行的完整文字；
- 如有播放失败，Debug 提示和错误提示的原文。

请勿公开带完整签名参数的视频下载地址、账号信息或令牌。诊断行只显示媒体域名和 Range 信息，不显示 URL 查询参数。

## 源码位置

- `tools/mac-port.cjs`：复制、注入和封装 Mac 应用；
- `src/bootstrap-mac.cjs`：在 Electron 会话中加入 preload；
- `src/client.js`：连接官方播放器事件；
- `src/transport.js`：筛选并接管媒体 `fetch`／XHR；
- `shared/`：与原项目共用的区间下载和 CDN 逻辑。

运行相关测试：

```sh
node --test test/mac-port.test.cjs test/transport.test.cjs test/auto-concurrency.test.cjs
```
